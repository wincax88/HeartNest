# 微信小程序主按钮箭头对齐设计

## 目标

修复微信小程序中 `HnPrimaryButton` 右侧箭头向下偏移、超出圆形容器的问题，同时保持按钮文字、左侧图标、渐变、阴影、尺寸和其他页面布局不变。

## 设计

- 将主按钮作为箭头定位的相对容器。
- 将右侧圆形箭头容器从普通 Flex 子项改为绝对定位：固定在按钮右侧，并使用 `top: 50%` 与 `translateY(-50%)` 垂直居中。
- 为箭头 `uni-icons` 宿主增加独立类名，固定其显示方式、宽高和行高，消除微信小程序自定义组件默认盒模型带来的纵向拉伸。
- 保留现有圆形描边、半透明背景和箭头图标，不改变交互行为。

## 平台与兼容性

样式继续放在共享的 `HnPrimaryButton.vue` 中。定位规则基于标准 CSS，在 H5、APP 和微信小程序均可使用；重点通过微信构建产物和现有 H5 构建验证，避免新增平台分支。

## 验收标准

1. 微信小程序中箭头位于按钮右侧圆形容器正中央。
2. 圆形容器始终位于按钮内部，且与右边缘保持固定距离。
3. “开始体验”文字仍保持视觉居中，不因箭头定位发生水平偏移。
4. 左侧声音图标、按钮尺寸、渐变、阴影和点击行为不变。
5. 现有测试、类型检查、H5 构建与微信小程序构建全部通过。

## 测试策略

- 先增加组件源码回归测试，断言按钮具有定位上下文、箭头使用绝对定位与垂直居中、图标宿主被显式归一化。
- 运行测试确认修复前失败，再实施最小样式修改。
- 重新生成微信小程序构建产物，检查对应 WXSS 包含预期定位规则。
- 运行全量测试、类型检查、H5 构建和微信小程序构建。
